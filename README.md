## Library Management Database
This project is a relational database system for managing a library. It stores information about members, authors, books, and loans.

# The system allows users to:
- View books
- View available books
- Add books
- Register members
- Check out books
- Return books
- View member borrowing history
- Database Tables

# The database contains the following relations:
- Members
- Authors
- Books
- Loans
- Technologies Used
- SQLite
- SQL
- Python

# How to Create the Database
Run: sqlite3 library.db < database/library.sql

# How to Run the Application
Run: python3 src/app.py

# SQL Query Requirements

Displaying all books
Displaying available books
Displaying books and their authors
Displaying members and borrowed books
Displaying active loans
Counting loans per member
